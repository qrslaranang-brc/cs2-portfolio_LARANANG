# Programming Exercises Reflection

## Exercise 1: Count Even Numbers
For this exercise, I learned how to control the step size inside Python's `range()` function. By setting the start value to 2, the stop value to 21, and the step to 2, I was able to print all even numbers up to 20 efficiently without needing extra if statements to check if a number was even.

## Exercise 2: The Countdown Timer
Using a while loop taught me the importance of tracking and updating a condition so that a loop doesn't run forever. Starting “count” at 10 and subtracting 1 (count -= 1`) during each cycle allowed the program to count down cleanly before printing "Time is up!" once the loop finished.

## Exercise 3: Skip Multiples
This exercise showed me how the modulo operator (`%`) and the `continue` statement work together to filter output. Checking `number % 3 == 0` made it easy to identify multiples of 3, and using continue let the program skip printing those specific numbers without stopping the rest of the loop.

## Exercise 4: Multiplication Table Generator
Creating show_table(number helped me understand how to combine functions, parameters, and loops. Accepting user input with int(input()) and passing that value as an argument into my function made the code reusable for any number, rather than hardcoding a single multiplication table.
